# Segun Adegbite — Portfolio

Custom Next.js portfolio redesigned for international freelance and remote opportunities. The visual language is editorial, asymmetric and product-focused rather than a standard template.

## Featured work
- IBARFFS Cooperative — cooperative/member/loan/ledger platform
- Serenity Touch NYC — service-business website and conversion-focused experience
- African Student Super App — student product/interface work
- Trading & Finance UI — dashboard and web interface work

## Local development
```bash
npm install
npm run dev
```

Production check:
```bash
npm run build
npm start
```

## Vercel
Standard Next.js App Router project. Push the repository to GitHub and import it into Vercel. No environment variables are required by this portfolio.
